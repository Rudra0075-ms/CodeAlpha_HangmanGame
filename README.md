# CodeAlpha Hangman Game

This is a simple text-based Hangman game created using Python
as part of my CodeAlpha Python Programming Internship.

## Features

- Contains 5 predefined words
- Randomly selects a word
- Allows the player to guess one letter at a time
- Allows 6 incorrect guesses
- Shows guessed letters
- Handles invalid and repeated inputs
- Displays win or game-over messages

## Technologies Used

- Python
- random module

## How to Run

1. Make sure Python is installed.
2. Open the project folder in the terminal.
3. Run:

python hangman.py

## Concepts Used

- Lists
- Strings
- Variables
- if-else
- while loop
- for loop
- Functions from the random module
- User input
